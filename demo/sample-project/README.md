# sample-project

A stand-in project for the live demo. Its dev container is a stock Ubuntu
image with nothing personal in it. Open it in a container twice:

1. With `dotfiles.repository` **unset** in your VS Code user settings: plain
   prompt, no `ll`, no `gs`, no `git lg`.
2. With it **set** (Rebuild Container): the same image, now with your prompt,
   aliases, git config and tools.

Same project, same `devcontainer.json`. The only thing that changed was a
setting on your machine.
